# 제주 관광 AI 실습

제주 관광 데이터를 활용해 AI 실습을 진행하는 저장소입니다.

## 폴더 구조

```
.
├── data/      # 실습 데이터
├── outputs/   # 결과물
├── prompts/   # 내 프롬프트 기록
└── README.md
```

## 폴더별 안내

### 📂 `data/` — 실습 데이터
AI 실습에 입력으로 사용하는 원본 자료를 넣습니다.
- 제주 관광지·맛집·숙소 목록 (CSV, Excel 등)
- 관광객 통계, 방문객 리뷰, 설문 결과
- 참고용 문서, 이미지, 지도 자료

> 원본 데이터는 되도록 수정하지 말고, 가공한 데이터는 파일 이름에 `_정제` 등을 붙여 구분하세요.

### 📂 `outputs/` — 결과물
AI를 활용해 만든 산출물을 저장합니다.
- 여행 코스 추천안, 관광지 소개글, 홍보 문구
- 데이터 분석 결과, 표, 차트, 보고서
- 생성한 이미지나 발표 자료

> 파일 이름에 날짜를 붙이면 관리가 쉽습니다. 예: `2026-11-03_3박4일_가족여행코스.md`

### 📂 `prompts/` — 내 프롬프트 기록
실습 중 AI에게 입력한 프롬프트와 그 결과에 대한 메모를 기록합니다.
- 사용한 프롬프트 원문
- 잘 된 점 / 아쉬운 점, 수정한 버전
- 어떤 `outputs/` 결과물과 연결되는지

> 예: `2026-11-03_여행코스추천.md` 에 프롬프트와 개선 과정을 함께 정리하세요.
